## 1. 内测须知

| 事项 | 说明 |
| --- | --- |

## 2. 安装 TestFlight

### 2.1 收到邀请

1. 确认已向运营提供用于 TestFlight 的 **Apple ID 邮箱**
2. 查收 Apple 发来的 **TestFlight 邀请邮件**，或打开系统通知
3. 若未收到，请检查垃圾邮件，或联系运营补发

### 2.2 安装步骤

1. 在 App Store 安装 **[TestFlight](https://apps.apple.com/app/testflight/id899247664)**（若尚未安装）
2. 打开 TestFlight → 接受「宝宝相机」邀请
3. 点击 **安装** 或 **更新**（有新版本时请先更新再测试）
4. 首次打开若提示「不受信任的开发者」，请到 **设置 → 通用 → VPN 与设备管理** 信任（通常 TestFlight 无需此步）

### 2.3 更新版本

有新 Build 时 TestFlight 会推送通知。测试前请确认 **版本号 / Build 号**，并在反馈 Bug 时一并说明。

## 4. 首次启动：登录与新手引导

### 4.1 登录

1. 打开「宝宝相机」
2. 输入 **11 位中国大陆手机号**（可用上表测试号）
3. 点击 **获取验证码** → 输入 **`123456`**
4. 同意用户协议与隐私政策后完成登录

### 4.2 新手引导（首次登录）

按屏幕提示依次完成（约 3–5 分钟）：

1. **创建或加入家庭** — 新建家庭，或通过邀请码加入已有家庭
2. **添加宝宝** — 填写昵称、生日、性别等
3. **监护人同意书** — 阅读并签署（涉及儿童信息处理，须完成后再使用发布、AI 等写操作）
4. 完成后进入 App **主界面**（底部 Tab 栏）

若中途退出，下次启动会从未完成步骤继续。

## 5. 主流程操作步骤

以下路径为内测 **每日最低体验**（约 5 分钟）。详细检查项可参考 [Bug Bash 清单](./BUG_BASH_CHECKLIST.md)，本手册仅保留操作步骤。

### 5.1 总览：底部 Tab

| Tab | 名称 | 主要功能 |
| --- | --- | --- |
| 1 | **相机** | 拍照、前后摄切换、连拍 |
| 2 | **成长** | 时间线（日/月/年）、地图、里程碑 |
| 3 | **家庭圈** | 发布动态、浏览 Feed、点赞评论 |
| 4 | **AI** | AI 玩法列表、提交任务、查看结果 |
| 5 | **我的** | 设置、积分、订阅、账号 |

顶栏可 **切换当前宝宝**（多宝宝家庭）；切换后相机、时间线、家庭圈内容应随之更新。

---

### 5.2 登录 → 拍照

**路径**：相机 Tab

1. 进入 **相机** Tab（首次会请求相机权限，请选择 **允许**）
2. 点击快门 **拍照**；可尝试前后摄像头切换、连拍多张
3. 拍照后应出现缩略图或进入下一步（选图/编辑）

**关注点**：权限拒绝时是否有引导去「设置」开启；低存储/低电量是否有提示。

---

### 5.3 拍照 → 编辑 → 保存

**路径**：相机 → 编辑器

1. 拍照完成后进入 **编辑器**（或从相册选图进入）
2. 尝试 **裁剪、滤镜、贴纸** 等；若有撤销/重做请各试一次
3. 点击 **保存/完成**，照片应写入本地 **成长时间线**

**关注点**：编辑后导出是否清晰；保存后能否在「成长」Tab 看到新照片。

---

### 5.4 成长时间线（Timeline）

**路径**：成长 Tab

1. 打开 **成长** Tab，查看刚保存的照片是否出现
2. 切换 **日 / 月 / 年** 视图
3. 若有 **地图** 入口，查看照片地理分布（需拍摄时带位置信息）
4. 可选：进入 **里程碑**，查看或添加里程碑事件

**关注点**：切换宝宝后时间线内容是否正确；下拉刷新是否正常。

---

### 5.5 家庭圈（发布与互动）

**路径**：家庭圈 Tab

1. 点击 **发布**（或「+」），选择照片并 **配文**
2. 可选：使用 **智能文案** 生成候选标题（会消耗配额/积分）
3. 发布成功后，在家庭圈 **Feed** 中应能看到自己的帖子
4. 用 **另一账号**（`13800138002`）登录同一家庭，尝试 **点赞、评论**
5. 可选：尝试 **撤回** 刚发布的帖子，确认 Feed 中不再展示

**关注点**：发布失败时的提示是否清楚；违规文案是否被拒绝并有说明。

---

### 5.6 AI 玩法

**路径**：AI Tab

1. 打开 **AI** Tab，浏览玩法列表（页内应有 **算法备案号 / 深度合成说明** 入口）
2. 选择一种 **图像玩法**，上传或选用宝宝照片，提交任务
3. 等待生成（弱网时可能较慢，可切到后台再回来查看）
4. 成功后 **保存结果** 到相册或时间线；若失败，留意是否有 **积分退还** 提示
5. 可选：尝试 **视频类玩法**（如 5 秒），注意积分预估与扣费是否一致

**关注点**：任务进行中切后台再返回是否正常；审核拒绝时是否有申诉入口。

---

### 5.7 设置与账号

**路径**：我的 Tab → 设置

1. 进入 **我的** → **设置**，浏览六个分区：
   - **账号** — 个人信息、登出
   - **家庭** — 成员、邀请
   - **隐私** — 权限与隐私相关
   - **数据** — 备份、导出、清理缓存
   - **通知** — 推送开关
   - **关于** — 用户协议、隐私政策、版本号
2. 尝试 **清理缓存**（可选，观察再次打开 Feed/Timeline 是否仍可用）
3. 可选：**数据导出**（生成 zip，可在 Mac 上打开查看）
4. 测试结束如需退出：**登出** 或 **注销账号**（注销有二次确认与冷静期说明，请 **勿用主号误操作**）

**关注点**：设置各入口是否都能打开；反馈邮件是否可正常发送。

## 7. 常见问题（FAQ）

### Q1：验证码填什么？收不到短信？

- **Staging 内测**默认使用固定验证码 **`123456`**，无需等待真实短信。
- 若提示验证码错误，请检查是否误输入空格；连续错误 3 次可能触发 **冷却**，稍后再试。
- 若运营通知已切换真实短信，请使用真实收到的 6 位码。

### Q2：必须授权哪些权限？

| 权限 | 用途 | 拒绝后 |
| --- | --- | --- |
| **相机** | 拍照 | 无法使用相机 Tab，App 应引导去系统设置开启 |
| **相册** | 选图、保存 | 选图/保存可能失败，按提示去设置 |
| **通知** | 家庭动态、AI 完成提醒 | 可继续使用，但可能收不到推送 |
| **位置**（可选） | 时间线地图 | 不影响拍照与发布 |

路径：**设置 → 宝宝相机 →** 对应权限。

### Q3：弱网或飞行模式下会怎样？

- **登录**：飞行模式应提示网络不可用，文案可读即可。
- **发布 / AI**：可能加载慢或失败；AI 任务可 **切后台**，完成后通过推送或重新进入 AI 页拉取结果。
- **浏览**：已缓存的时间线、Feed 在弱网下宜仍可 **离线浏览**（若不可用请反馈）。

测试建议：在 Wi‑Fi 与 **4G/5G** 各测一轮；可用「设置 → 开发者 / 网络链路调节器」模拟弱网（若设备支持）。

### Q4：积分、订阅、广告怎么测？

- 新用户可能有 **赠送积分**；AI 消耗后可在「我的」查看余额与流水。
- **订阅 / 内购** 使用 Apple **沙盒账号**，不会产生真实扣款（沙盒账号由运营单独发放）。
- **激励广告** 有每日上限与冷却，重复观看应提示已达上限。

### Q5：微信分享失败？

- 需设备安装 **微信**；未安装时应提示清晰，而非崩溃。
- 也可使用 **系统分享** 或复制链接到小红书/抖音等（按 App 内引导操作）。

### Q6：App 崩溃或闪退怎么办？

1. 记录 **机型、iOS 版本、Build 号、操作步骤**
2. 打开 TestFlight → 宝宝相机 → **发送 Beta 反馈**（可附截图/录屏）
3. App 内 **设置 → 反馈** 提交（日志已脱敏，不含密码）
4. 严重问题（无法登录、丢照片）请在内测群 **@运营** 标注 **紧急**

### Q7：可以多台手机、多个宝宝吗？

- 可以。同一 Apple ID 仅对应 TestFlight 安装；**不同手机号** 可登录不同测试账号。
- 家庭内可添加 **多个宝宝**，请测试顶栏 **切换宝宝** 后各 Tab 内容是否一致。

### Q8：测试数据会被删除吗？

- 内测数据位于 **Staging 环境**，可能随版本迭代 **重置**；请勿仅依赖内测环境保存唯一照片，重要素材请自行备份。

## 8. 如何反馈 Bug

反馈质量越高，修复越快。请尽量包含：

1. **标题**：一句话说明问题（例：「发布家庭圈后 Feed 不刷新」）
2. **环境**：TestFlight Build 号 · iOS 版本 · 机型（例：iPhone 15 / iOS 18.1）
3. **账号**：使用的测试手机号（勿发密码）
4. **步骤**：1、2、3 如何复现
5. **期望 / 实际**：应该怎样 · 实际怎样
6. **附件**：截图或 **屏幕录制**（Settings → 控制中心 可添加入口）

| 渠道 | 适用 |
| --- | --- |
| App 内「设置 → 反馈」 | 默认，推荐 |
| TestFlight「发送 Beta 反馈」 | UI 问题、崩溃 |
| 飞书群「宝宝相机内测」 | 当日紧急 P0（崩溃、无法登录、丢图） |

**严重级别参考**（便于运营分拣）：

- **P0**：崩溃、数据丢失、无法登录、付费未到账
- **P1**：主流程阻断但可绕行
- **P2/P3**：体验问题、文案、UI 细节

研发用完整缺陷模板见 [Bug Bash 清单 §5](./BUG_BASH_CHECKLIST.md#5-缺陷记录模板)。

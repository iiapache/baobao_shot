## 1. 使用说明

1. 每条用例执行后标记：`☐ 未测` → `✓ Pass` / `✗ Fail` / `— N/A`
2. Fail 须登记：标题 · 复现步骤 · 期望/实际 · 截图或录屏 · 严重级（P0–P3）
3. P0 定义：崩溃、数据丢失、无法登录、付费未到账、审核漏放违规内容
4. 关键路径参考：`tests/e2e/smoke-critical-path.sh`（API mock）+ 端侧真机同路径

## 8. 反馈与升级通道

| 渠道 | 用途 |
| --- | --- |
| App 内「设置 → 反馈」 | 默认渠道，附脱敏日志 |

| TestFlight 截图反馈 | 补充 UI 问题 |

**升级 build 条件**：P0 修复验证通过 或 崩溃率单日 > 0.5%。

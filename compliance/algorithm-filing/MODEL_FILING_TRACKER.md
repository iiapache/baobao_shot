## 状态定义

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 材料准备中 | 清单未齐，尚未提交 | 对照 DEEP_SYNTHESIS_CHECKLIST 补齐 |
| 已提交·待受理 | 已线上提交，等待回执 | 每日查受理状态，超 7 天升级 |
| 已受理·审核中 | 有受理号，审核进行中 | 周状态跟踪；响应补正 |
| 补正中 | 收到补正通知 | 3 个工作日内提交补正材料 |
| 已通过 | 获批，有正式备案号 | 触发 T7.1 回填流程 |
| 已驳回 | 申报被驳回 | 法务评估后决定重报或调整模型 |

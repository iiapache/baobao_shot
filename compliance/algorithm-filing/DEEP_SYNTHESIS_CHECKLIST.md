## 二、深度合成内容标识技术要求

依据 PRD §6.2 与 design-backend §5.6，V1 全链路须满足：

### 2.1 显式标识（强制、不可关闭）

| 项 | 规格 | 实现位置 |
| --- | --- | --- |
| 角标文案 | `AI 生成 · 深度合成` | 后端 watermarking 阶段 |
| 位置 | 右下角 | WatermarkRenderer |
| 尺寸 | 短边 ≥ 5% 且 ≤ 8% | 合规 QA 用例 |
| 透明度 | 背景 60% 不透明，文字 100% | 设计稿已定 |
| 适用范围 | 图像 + 视频（首帧 / 角标叠加） | ai-dispatch-svc |
| 用户控制 | **不可关闭**（品牌水印订阅可关，深度合成标识强制） | PRD §4.5.4 |

### 2.2 隐式标识（元数据写入）

| 媒介 | 写入方式 | 字段示例 |
| --- | --- | --- |
| 图像（PNG/JPEG） | XMP / EXIF | `XMP-dc:Source = "AIGC:baobao/seedream"` |
| 视频（MP4/H.264） | `udta` 自定义标签 | `AIGC-Producer`, `AIGC-Model`, `AIGC-FilingNo` |
| 数据库 manifest | `deepSynth.manifest` 集合 | vendor, model, prompt_hash, created_at, **filing_no** |

### 2.3 分享链路

- 分享前客户端 `WatermarkRenderer` 校验显式标识存在（T5.15）
- 分享导出文件须保留隐式标识
- 视频分享可选重新压制，但深度合成角标不可去除
